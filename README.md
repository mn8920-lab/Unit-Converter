# Web Unit Converter

A lightweight, responsive, dark-themed web unit converter built using pure HTML, CSS, and vanilla JavaScript. 

## Features
- **Real-time Conversion**: Instantly converts metrics as you type or change units.
- **Multiple Categories**: Supports Length, Weight/Mass, and Temperature.
- **GitHub Dark Aesthetics**: Beautifully designed UI matching modern developer themes.
- **Zero Dependencies**: Pure client-side implementation with no NPM packages required.

## Local Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/unit-converter.git
   ```
2. Open `index.html` directly in any web browser.

## Deployment
You can host this project completely free using [GitHub Pages](https://pages.github.com/). Go to your repository settings, navigate to **Pages**, and select your main branch as the deployment source.
